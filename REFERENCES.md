# Visual references

Give these to Claude at the start of a session so it has a target
instead of guessing.

## The feel we want

Quiet, expensive, editorial. A property page should feel like a printed
brochure from a good architecture practice — not a listings portal.

## Sites to borrow from, and what from each

- **Aman / Six Senses (hotel sites)** — full-bleed photography with
  almost no UI on top of it. Text sits beside images, not over them.
- **Kinfolk / Cereal (editorial)** — the serif-and-sans pairing we are
  already using, and the confidence to leave a lot of empty space.
- **Linear** — spacing discipline and consistent vertical rhythm. Every
  section uses the same gap system.
- **Stripe** — scroll pacing. Things reveal calmly as you move, and
  never compete for attention.

## What to avoid, explicitly

Indian real estate sites usually look like: hero carousel with three
rotating slides, a yellow "ENQUIRE NOW" button fixed to the corner,
badge icons for "RERA Approved / Vastu Compliant / 24x7 Security",
gradient overlays on every photo, and a counter that animates to
"500+ Happy Families".

We are doing the opposite of all of that. That contrast is the product.

## Hierarchy on a property card

Photo → locality → price → configuration → possession status → RERA ID.
Price is the second thing the eye lands on, never the first.
